AEGIS Language Overview

AEGIS (Adaptive Execution Guarded Interpreter System) is a minimal, imperative programming language designed around a security-first execution model. Rather than blindly running code, AEGIS evaluates trust and adjusts its execution strategy accordingly.

Core Principles

  • Security by default — all programs start sandboxed
  • Progressive trust — repeated safe runs build a trust score
  • Trust-gated optimisation — only trusted code gets optimized
  • Full pipeline transparency — see exactly what happens at each stage

Quick Start

Start the server with python webapp/server.py, then open the Playground tab and write your first program:

# Assign a value and print it
x = 42
print x

Syntax

AEGIS uses indentation-free, line-based syntax. Blocks are terminated with the end keyword.

Assignment

x = 10
name = 42

If / Else

if x > y
  result = x
else
  result = y
end

While Loop

while i < 5
  print i
  i = i + 1
end

Comments

# This is a comment — everything after # is ignored

The AEGIS Pipeline

Every program you run passes through five stages before any output appears.

StageWhat it does
📝 LexerConverts raw source text into a flat stream of typed tokens
🌳 ParserBuilds an Abstract Syntax Tree (AST) from the token stream
🔍 AnalyzerPerforms semantic checks: type safety, undefined variables, division-by-zero detection
🛡️ Trust GuardLooks up code hash in the trust database; applies sandbox restrictions or grants optimizations
⚡ ExecutorWalks the AST and evaluates each node; trusted programs use the optimizer first

Trust Model

AEGIS tracks a trust score per unique code hash (SHA-256). Each successful, safe execution increments the score. Higher scores unlock faster execution paths.

0.0 – 0.1
NONE — fully sandboxed, all operations checked
0.1 – 0.3
LOW — building trust through repeated safe runs
0.3 – 0.6
MEDIUM — gaining trust, reduced sandbox overhead
0.6 – 0.8
HIGH — near-optimized, most checks skipped
0.8 – 1.0
TRUSTED — optimizer enabled, maximum performance ⚡

Run the Trust Builder example in the Playground repeatedly to watch the score climb in real time.

About AEGIS

AEGIS is a research-grade, security-first programming language and runtime built to explore adaptive execution models — where the interpreter itself becomes smarter and faster as code proves safe over time.

🔧 Technical Stack

  • Language runtime written in Python
  • Hand-written recursive-descent parser
  • Visitor-pattern AST evaluator
  • SHA-256 code hashing for trust tracking
  • Flask REST API for web integration
  • Vanilla HTML/CSS/JS frontend (no build step)

🛡️ Security Model

AEGIS treats security not as an afterthought but as the core execution primitive. Programs are sandboxed by default. The static analyzer catches division-by-zero, undefined variables, and infinite-loop risks before execution. Trust scores are persisted across sessions so frequently-run safe programs automatically unlock the optimizer.

📁 Project Structure

  • aegis/lexer/ — Tokenizer
  • aegis/parser/ — AST builder
  • aegis/ast/ — AST node definitions
  • aegis/interpreter/ — Evaluator + analyzer
  • aegis/compiler/ — Optimizer
  • aegis/pipeline.py — Execution pipeline
  • webapp/ — This web dashboard
